System Snapshot Tool

A lightweight Python CLI tool for collecting and presenting system information in a readable report.

The project started as a simple, "neofetch"-inspired system information utility and is being developed towards a more structured diagnostic tool.

Project Goals

- Collect relevant operating system and hardware information.
- Present system details in a clear, readable format.
- Handle platform-specific differences and unavailable information gracefully.
- Provide a foundation for saving and comparing system snapshots.

Current Features

The initial version is under development.

Currently implemented:

- Operating system identification
- Kernel identification
- OS distribution identification on supported Linux systems
- System architecture identification
- Hostname retrieval

Additional features will be documented as they are implemented and tested.

Planned Features

- OS version and device identification
- CPU information, including core and thread counts where available
- RAM and memory usage information
- Disk and storage capacity information
- Structured system reports
- Saving snapshots for later use
- Comparing snapshots to identify configuration and measurement changes
- Improved cross-platform compatibility

Supported Platforms

Cross-platform support is a development goal.

Platform compatibility and feature availability will be documented based on actual testing. Some information may be unavailable depending on the operating system, hardware, permissions, or data sources.

Requirements
